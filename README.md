# StageRehearsal（舞台剧排练预演）

在 PC 上模拟舞台剧排练情况的桌面软件：以俯视角观察整个舞台，安排演员、屏风和舞台道具的走位，并通过时间轴关键帧编排整场演出的调度与场次节奏。

## 功能

- 俯视角 2D 舞台（单位 cm，网格可配）：滚轮缩放、右键拖动平移；舞台尺寸 / 中心点 / 颜色与台下准备区在〈设置-舞台〉中可视化编辑
- 演员（圆形 + 朝向三角）、屏风（矩形）和舞台道具可创建编排，名称全局不可重复；道具支持多边形与弧边形状编辑、宽高缩放和可供站立设置，空对象用于层级整理
- 拖拽移动、方向键微调、框选 / 多选、复制 / 粘贴 / 删除；对象、路径、关键帧和资源清单的修改支持撤销 / 重做
- 全局时间轴以关键帧（位置 + 朝向）编排调度：播放 / 倍速 / 场次标签，主视口实时联动；相邻关键帧间支持直线、弧线路径与路径点编辑
- Unity 风格可停靠布局：主视口、Hierarchy、Inspector、时间轴与资源库；资源库默认位于 Hierarchy 下方、时间轴左侧
- 项目资源库支持导入、重命名和移除图片与音频，实际文件复制到项目的 `Assets/audio` 或 `Assets/images`；Inspector 提供图片预览与音频试听
- 启动页可新建项目或打开最近项目

## 技术栈

- C++17，Qt 6（≥ 6.4）：界面用 Widgets，主视口用 QGraphicsView/QGraphicsScene，音频试听用 Qt Multimedia（QMediaPlayer/QAudioOutput）
- JSON 序列化使用 QJson（QJsonDocument/QJsonObject）
- CMake（≥ 3.20）构建，编译器 MSVC 2022，目标平台 Windows
- 代码按数据层 / 业务层 / 渲染层三层组织
