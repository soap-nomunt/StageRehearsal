## VS 启动窗口风格解剖（设计参照）
- 左侧："打开最近使用的内容"——搜索框过滤 + 最近项目列表（每项 = 项目名加粗 + 完整路径灰色小字 + 最近打开时间），单击条目即打开

## 本阶段任务

1. **最近使用列表（AppSettings 扩展）**
   - 新增 `QStringList recentFiles() const`、`void addRecentFile(const QString& path)`、`void removeRecentFile(const QString& path)`；QSettings 键 `recentFiles`
   - MRU 语义：addRecentFile 去重（Windows 路径大小写不敏感比较）后置顶、上限 10 条截断；removeRecentFile 按同一比较移除
   - 记录时机在数据层：`RuntimeData::openFile` 成功、`RuntimeData::saveFile` 成功（另存为后的当前文件也入 MRU）；openFile 失败不记录

2. **启动页 `StartDialog`（新文件 `src/render/StartDialog.h/.cpp`，模态 exec）**
   - 布局参照 VS 启动窗口：左侧"打开最近使用的内容"（搜索框 `recentSearchEdit` 占位文本"搜索最近使用的存档" + 列表 `recentFilesList` QListWidget），右侧"开始使用"操作区三个入口（按钮 + 灰色说明小字，沿用设置窗口的灰色小字风格）：
     - `openOtherButton` "打开存档(&O)..."（说明：浏览本机存档文件）→ `QFileDialog::getOpenFileName`（原生对话框 offscreen 不可驱动，列手测）；取到路径则接受对话框，取消则留在启动页
     - `newProjectButton` "新建项目(&N)"（说明：从默认空舞台开始）→ 接受对话框
     - `emptyProjectButton` "直接进入空项目(&E)"（说明：不打开任何文件）→ 接受对话框
   - 列表项文本两行：`文件名` + `完整路径`（第二行可用灰色）；**单击条目即选择该存档**（接受对话框）；搜索框对文件名+路径做大小写不敏感包含过滤；列表为空/无匹配时显示占位 `recentEmptyLabel`（"暂无最近使用的存档，从右侧新建或打开" / "无匹配的最近存档"）
   - 对外 API：`enum class Choice { NewProject, OpenPath, Empty }; Choice choice() const; QString selectedPath() const;`（OpenPath 时有效）
   - Esc/标题栏关闭 = reject（调用方据此退出程序）
   - 持有自己的 `AppSettings` 成员读/写最近列表（QSettings 同一存储，不依赖 MainWindow/RuntimeData，与 main.cpp 流程解耦）；深色风格与现有界面协调即可，不追求像素级复刻 VS

3. **启动流程改造（main.cpp + MainWindow 构造函数）**
   - MainWindow 构造函数：删除示例存档自动加载与失败退回逻辑（构造即默认空舞台），`updateWindowTitle()`/`resetView()` 保留；构造不再产生任何文件 IO
   - main.cpp 新流程：解析参数判断截图自测模式（`--selftest-screenshot=`）→
     - 截图模式：**保持旧行为**，直接 `window.openFromPath(applicationDirPath + "/stage-demo.json")`（不弹启动页，`dumpScreenshotForSelfTest` 验收路径不变）
     - 正常模式：循环 `StartDialog dialog(&window); dialog.exec()`——reject → 直接 `return 0` 退出程序；`NewProject`/`Empty` → 跳出（构造已是空舞台）；`OpenPath` → `window.openFromPath(selectedPath())`，成功跳出，失败（openFromPath 已弹提示）则 `removeRecentFile` 移除该失效条目并重新弹启动页
   - 全部完成后再 `window.show()`；启动页只在正常启动出现一次

4. **自测更新（既有 518+314 用例适配后零回归）**
   - InteractionSelfTest 启动适配：main() 构造 MainWindow 后显式 `openFromPath` 示例存档再断言；阶段6 w2 块、阶段7 w6 块同样补显式加载
   - 新增 StartDialog 用例（非模态实例化直查控件，不经 exec）：准备 MRU 哨兵 → 列表行数与顺序（去重置顶）；搜索过滤命中/无匹配占位；单击条目（可直调 `itemClicked` 信号）→ `choice()==OpenPath` 且 `selectedPath()` 正确、对话框 accept；`newProjectButton->click()` → NewProject；`emptyProjectButton->click()` → Empty；清空最近列表后占位提示可见。打开存档按钮走原生文件对话框 → 列手测
   - DataLayerSelfTest：addRecentFile 追加/去重置顶/超 10 条截断/removeRecentFile/跨实例读回；RuntimeData::openFile 成功入 MRU、saveFile 成功入 MRU、openFile 失败不入
